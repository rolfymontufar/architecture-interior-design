# Mobiliario / Furniture

> Estado / Status: COMPLETADO (fase 2) / DONE (phase 2).
> Medidas del mueble en cm: ancho x fondo x alto. Holgura = espacio libre de uso frente o alrededor del mueble.
> / Furniture sizes in cm: width x depth x height. Clearance = clear use space in front of or around the item.
> Colchón: ancho x largo (largo en columna Prof.). / Mattress: width x length (length in Depth column).
> US = estándar EE. UU. (convertido de pulgadas) / US standard (converted from inches); EU = estándar europeo / European standard.
> RP = Regla práctica / Rule of thumb. "(a verificar / to verify)" = sin fuente sólida.
