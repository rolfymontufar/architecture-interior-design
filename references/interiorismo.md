## Resumen rápido / Quick reference

- **Cuadro / Art:** centro a 145-152 en muro libre; 15-20 sobre el mueble; ancho ≈ 2/3 del mueble.
- **Colgante / Pendant:** 76-91 sobre mesa o isla (borde inferior); ≥ 213 libre en zonas de paso.
- **Apliques / Sconces:** centro a 152-168; apliques de espejo separados 71-102.
- **Cortina / Curtain rod:** 10-15 sobre el marco, o cerca del techo; cortina rozando el piso.
- **TV:** centro de pantalla 110-125 (100-110 con sofá bajo o reclinable); distancia 1.2-1.6 x diagonal. Canónico / Canonical: `ergonomia.md`, `sala-comedor.md`.
- **Sofá a mesa de centro / Sofa to coffee table:** 40-45 (mín. 35). Canónico / Canonical: `sala-comedor.md`.
- **Alfombra sala / Living rug:** 240 x 300 estándar; patas delanteras encima.
- **Color:** 60-30-10. **Kelvin:** 2700 K estar y dormir; 3000-3500 K cocina; CRI ≥ 90.
- **Lux:** ver / see `confort-ambiental.md` (ubicación canónica / canonical location).
- **Acústica ES / Spain acoustics:** entre viviendas DnT,A ≥ 50 dBA; tabiques propios RA ≥ 33 dBA.

## B1. Principios de diseño / Design principles

| Principio / Principle | Definición / Definition | Aplicación / How to apply |
|---|---|---|
| Equilibrio / Balance | Peso visual repartido: simétrico, asimétrico, radial / Visual weight distributed: symmetric, asymmetric, radial | Simétrico = formal (par de lámparas); asimétrico = casual (sofá vs. 2 sillones) / Symmetric = formal; asymmetric = casual |
| Ritmo / Rhythm | Repetición, alternancia, gradación / Repetition, alternation, gradation | Repetir color o material 3 veces en la sala / Repeat a color or material 3 times in a room |
| Énfasis / Emphasis | Punto focal dominante / Dominant focal point | Un solo foco por espacio (chimenea, vista, cuadro, cabecero) / One focal point per room |
| Escala / Scale | Tamaño respecto al espacio y al cuerpo / Size relative to room and body | Muebles grandes en espacios pequeños saturan; techos altos piden piezas más altas / Big furniture overwhelms small rooms |
| Proporción / Proportion | Relación entre partes / Ratio between parts | Mesa de centro ~2/3 del largo del sofá; cuadro ~2/3 del ancho del mueble inferior (Regla práctica / Rule of thumb, HG) |
| Unidad y variedad / Unity and variety | Coherencia con contraste controlado / Coherence with controlled contrast | Paleta y materiales limitados; un contraste fuerte / Limited palette; one strong contrast |
| Armonía / Harmony | Elementos que comparten lenguaje / Elements sharing a language | Mismo estilo de herrajes, tono de madera dominante / Same hardware style, dominant wood tone |
| Agrupación impar / Odd grouping | Objetos en grupos de 3 o 5 / Objects in groups of 3 or 5 | Regla práctica / Rule of thumb (decoración / styling) |

## B2. Color

| Regla / Rule | Valor / Value | Fuente / Source |

| Esquema / Scheme | Descripción / Description | Efecto / Effect |
|---|---|---|
| Monocromático / Monochromatic | Un tono en varios valores / One hue, several values | Calma, amplitud / Calm, spaciousness |
| Análogo / Analogous | 2 a 3 tonos vecinos en el círculo / 2 to 3 adjacent hues | Armonía suave / Soft harmony |
| Complementario / Complementary | Tonos opuestos / Opposite hues | Contraste, energía; usar uno como acento / Contrast; use one as accent |
| Complementario dividido / Split complementary | Un tono + los 2 vecinos de su opuesto / One hue + 2 neighbors of its complement | Contraste más suave / Softer contrast |
| Triádico / Triadic | 3 tonos equidistantes / 3 equidistant hues | Vibrante; dominar uno / Vibrant; let one dominate |
| Neutro + acento / Neutral + accent | Blancos, grises, beiges + 1 color / Whites, greys, beiges + 1 color | Versátil, atemporal / Versatile, timeless |

- Cálidos (rojo, naranja, amarillo) avanzan y acogen; fríos (azul, verde, violeta) retroceden y calman. / Warm colors advance and feel cozy; cool colors recede and calm.
- Orientación: cuartos con luz fría (polo) admiten tonos cálidos; cuartos soleados admiten fríos. / Rooms with cool pole-facing light suit warm tones; sunny rooms suit cool tones.
- Espacio pequeño / Small room: muros, techo y molduras en tonos claros afines; mismo color muro-techo borra límites; cortinas del color del muro; pisos continuos entre espacios. Regla práctica / Rule of thumb.
- Techo oscuro baja visualmente el techo; muro del fondo oscuro acorta un pasillo largo. / Dark ceiling lowers it visually; dark end wall shortens a long hallway.
- Probar muestras de pintura de ≥ 30 x 30 cm (Regla práctica / Rule of thumb) en distintas paredes y horas. / Test swatches on several walls and times of day.

## B8. Textura, patrón y estilo / Texture, pattern and style

- Textura: combinar ≥ 3 texturas (liso, rugoso, brillante, mate, natural) para evitar planitud; espacios neutros dependen más de la textura. Regla práctica / Rule of thumb.
- Patrón: mezclar en 3 escalas (grande, mediano, pequeño) unidas por un color común; un patrón dominante. Regla práctica / Rule of thumb.
- Patrones grandes amplían visualmente si son de bajo contraste; rayas horizontales ensanchan, verticales elevan. / Large low-contrast patterns enlarge; horizontal stripes widen, vertical raise.

## B9. Acústica básica / Basic acoustics

| Concepto / Concept | Definición / Definition | Valor / Value | Fuente / Source |
|---|---|---|---|
| Absorción / Absorption | Reduce reverberación dentro del espacio / Reduces reverberation within a room | NRC 0 (refleja) a 1 (absorbe) / 0 reflects to 1 absorbs | OEP |
| Aislamiento / Insulation | Reduce transmisión entre espacios (masa, hermeticidad, desacople) / Reduces transmission between rooms | Rw, STC, DnT,A (dB, mayor = mejor / higher = better) | OEP |
| Tiempo de reverberación / Reverberation time (RT60) | Tiempo para caer 60 dB / Time to decay 60 dB | Sala de estar 0,3 a 0,6 s; dormitorio ~0,5 s | SA |
| Aislamiento aéreo entre viviendas (ES) / Airborne between dwellings (ES) | DnT,A | ≥ 50 dBA | DBHR |
| Ruido de impacto entre viviendas (ES) / Impact between dwellings (ES) | L'nT,w | ≤ 65 dB | DBHR |
| Tabiquería interior misma vivienda (ES) / Internal partitions same dwelling | RA | ≥ 33 dBA (residencial privado / private residential) | DBHR |

- Absorber: alfombras, cortinas gruesas, muebles tapizados, librerías llenas, paneles acústicos, techo acústico. / Absorb with rugs, heavy curtains, upholstery, full bookcases, panels.
- Aislar: muros con masa o yeso laminado doble con lana mineral en la cavidad; sellar juntas y pasos de instalaciones; puertas macizas con burlete. / Insulate with mass or double drywall with mineral wool; seal gaps; solid-core doors with seals.
- Espacios con superficies duras (porcelanato, vidrio, concreto) y doble altura reverberan: compensar con ≥ 1 superficie grande absorbente. Regla práctica / Rule of thumb.
- No ubicar dormitorios contra muro de TV, cocina, garaje o escalera; ver A5 en `conceptos.md`. / Keep bedrooms away from TV, kitchen, garage or stair walls.
