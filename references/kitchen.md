### Single-wall kitchen
| Level | Size | Area | Min side | Source |
|---|---|---|---|---|
| Minimum | e.g. 1.70 x 3.50 | 6 | 1.67 (0.60 counter + 1.07 aisle) | AH-F, NKBA-K6 |
| Recommended | e.g. 2.00 x 4.00 | 8 | 1.70; run ≥ 2.44 | AH-F, DF |
| Generous | e.g. 2.20 x 4.60 | ~10 | 1.80; run ≥ 4.30 | RT (NKBA-K11/16/17/24 calc.) |

- Clearances: work aisle ≥ 107 in front of the run (NKBA-K6). A ~4.3 m run fits fridge 76 + combined landings 91 + sink 76 + 76 + cooktop 76 + 30 (calc. with US appliances).
- Mistakes: cooktop or fridge tight to end wall with no landing (≥ 30/38); sink at run end without 61 on one side; run < 2.4 m with no 91 cm prep zone.
