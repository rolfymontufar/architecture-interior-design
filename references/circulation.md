## Blondel's formula
- 2R + T = 62 to 64 cm (R riser, T tread); ideal 63 (NEUF). Code range: ES general use 54 ≤ 2R + T ≤ 70 (CTE-SUA); UK 55 ≤ 2R + G ≤ 70 (UK-K).
- Comfortable pairs (RT): R 17 + T 29 = 63; 17.5 + 28 = 63; 18 + 27 = 63. Compact dwelling: 19 + 25 = 63 acceptable; 20 + 22 = 62 is the CTE restricted-use limit.
- Number of risers n = floor-to-floor height / R, round up (280 / 17.5 = 16). Plan length = (n - 1) x T (15 x 28 = 420). Check headroom ≥ 200 along the whole run.
