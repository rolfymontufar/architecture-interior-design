# Germany: residential minimums
Codes: Musterbauordnung (MBO) and the 16 Landesbauordnungen (LBO), e.g. Bayerische Bauordnung (BayBO) Art. 45 (Aufenthaltsräume) and Art. 46 (Wohnungen); DIN 18065:2020-08 (Gebäudetreppen); DIN 18040-2:2011-09 (barrier-free housing), under revision (new edition expected autumn 2026) (fs: nullbarriere.de); DIN 18011 (Stellflächen, Abstände und Bewegungsflächen im Wohnungsbau, 1967 edition; current status (av)). State (Land) level. No minimum dwelling size in the LBOs (exists in each Land's subsidised-housing rules, n/r here). DIN 18040-2 binding only where the LBO introduces it as Technische Baubestimmung. "R" = wheelchair (R-Wohnung).

| Metric | Value | Article |
|---|---|---|
| Bedroom, living, kitchen, dwelling area | n/r | MBO / LBO |

| Windows | ≥ 1/8 of net floor area | MBO § 47 (2) |
| Stair (≤ 2 dwellings) | width 0.80; riser 0.14-0.20; tread 0.23-0.37 | DIN 18065 (fs) |
| Doors | 0.80 (R and common routes 0.90); height 2.05 | DIN 18040-2 (fs) |
| Hallway | 1.20 (1.50 up to 15 m) | DIN 18040-2 (fs) |
| Manoeuvring | 1.20 x 1.20 (R 1.50 x 1.50) | DIN 18040-2 (fs) |
| Clearance in front of kitchen | ≥ 1.20 (R 1.50) | DIN 18040-2 (fs) |
