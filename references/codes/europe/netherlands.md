# Netherlands: residential minimums
Codes: Besluit bouwwerken leefomgeving (Bbl), under the Omgevingswet (in force 01/01/2024); chapter 4 = new build (nieuwbouw). Version consulted: geldend 01/01/2026. National, use function "woonfunctie" (values for "andere woonfunctie"; student housing and woonwagen differ). Verblijfsgebied = habitable zone; verblijfsruimte = habitable room.

## Accessibility
Accessibility sector (toegankelijkheidssector): living room ≥ 14 m² with width ≥ 3.2 m; accessible WC 1.65 x 2.20 m; bathroom 1.6 x 1.8 m; bathroom + WC 2.2 x 2.2 m (art. 4.186-4.187; scope within the dwelling (av)).
