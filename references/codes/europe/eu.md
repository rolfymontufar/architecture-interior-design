# European Union: residential minimums
Codes: no EU-level minimum dwelling or room sizes; each country (sometimes each region or municipality) sets them. EN 17210:2021 "Accessibility and usability of the built environment: Functional requirements" (CEN/CENELEC JTC 11), with CEN/TR 17621 (technical criteria) (av): voluntary functional standard, used in public procurement and as reference; binding only if a Member State adopts it. Eurocodes: structural only, no room dimensions.
