# Catalonia, Spain: residential minimums
Codes: Decret 141/2012, de 30 d'octubre, condicions mínimes d'habitabilitat dels habitatges i cèdula d'habitabilitat (DOGC 6245, 02/11/2012). Annex 1 = new build (cited clauses); Annex 2 = existing. Later amendments (e.g. dwellings with complementary shared spaces) (av). Regional, in force. Stairs and ventilation otherwise per CTE (spain-cte.md).

## Quick reference
| Metric | Value | Clause (Annex 1) |
|---|---|---|
| Min. dwelling | 36 m² useful | 3.1 |
| Living + dining + kitchen | ≥ 20 m², circle Ø 2.80 | 3.7.1, 3.7.2 |
| Min. bedroom | 6 m² (8 m² for 2 persons (fs)) | 3.8 |
| Bedroom side | square 2.00 x 2.00; one 2.60 x 2.60 if ≥ 3 bedrooms | 3.8 |
| Kitchen clear passage | ≥ 1.00 m | 3.7.3 |
| Ceiling height | 2.50 (2.20 bathrooms, kitchens, circulation) | 3.5 |
| Hallway | 1.00 to practicable rooms; 0.90 rest | 3.4.1 d |
| Doors | 0.80 entrance and practicable; 0.70 rest; height 2.00 | 3.4.1 c, 3.4.2 |
| Internal stair width | 0.90 | 3.4.3 |
| Daylight and ventilation openings | ≥ 1/8 of useful floor area | 3.9.1 |

## Rooms
| Item | Value | Clause |
|---|---|---|
| Min. dwelling | ≥ 36 m² useful; living-dining, bathroom (cámara higiénica) and kitchen equipment; if a single space, must allow partitioning an 8 m² room | 3.1 |
| Living + dining + kitchen (EMC) | ≥ 20 m² (unless municipal rule) | 3.7.1 |
| Living / dining dimensions | circle Ø 2.80 m; façade contact ≥ 2.20 m; narrowings ≥ 1.60 m | 3.7.2 |
| Kitchen | clear passage ≥ 1.00 m between work front and other elements; if integrated, vertical opening ≥ 3.50 m² | 3.7.3 |
| Min. bedroom | ≥ 6 m² (8 m² for 2 persons (fs)) | 3.8 |
| Bedroom side | inscribed square 2.00 x 2.00 m; in dwellings with ≥ 3 bedrooms, one with 2.60 x 2.60 m; not invaded by doors or wardrobes | 3.8 |
| Wardrobe per bedroom | depth 0.60 m, height 2.20 m, length 1.00 m (> 6 m²) or 1.50 m (> 8 m²) | 3.10.1 |
| Sanitary fixtures | 0-3 bedrooms: 1 WC, 1 basin, 1 shower/bath; ≥ 4: 2 WC, 2 basins, 1 shower/bath | 3.11.1 |
| Bathroom area | n/r (fixture count only) | n/a |
| Useful area exclusion | height < 1.90 m (flat ceiling) or < 1.50 m (roof ≥ 45°) does not count | 1 |
| Min. façade | perimeter ≥ S/9 (linear m) | 3.6.2 |

## Circulation
| Item | Value | Clause |
|---|---|---|

## Accessibility

## Comfort
| Item | Value | Clause |
|---|---|---|
| Ceiling height | ≥ 2.50 m; ≥ 2.20 m in bathrooms, kitchens and circulation; 2.30 m locally in ≤ 20 % of the room | 3.5 |
| Daylight and ventilation | openings ≥ 1/8 of useful area (between 0 and 2.5 m height) in common rooms and bedrooms | 3.9.1 |
| Ventilation | same openings (1/8) + CTE + kitchen extract | 3.9.1 |
| Light wells | circle Ø 3 m and 9 m² (bedrooms/rooms); Ø 2.5 m and 6 m² (kitchens, bathrooms, stairs), up to 3 floors | 2.5.1 |
