- **Cálculo / Derivation:** sofá 85-95 + holgura 40-45 + mesa de centro 50-60 + holgura 40-45 + sillón 80-90 = 2.95-3.35 m entre respaldos; sumar 90 si hay paso detrás. / Sofa 85-95 + gap 40-45 + coffee table 50-60 + gap 40-45 + armchair 80-90 = 2.95-3.35 m back to back; add 90 if a walkway runs behind. (CALC, profundidades típicas, ver / typical depths, see `mobiliario.md`)
- **Holguras clave / Key clearances:** sofá a mesa de centro 40-45 cm; paso principal 90 cm; TV a 1.2-1.6 x diagonal (ver tablas abajo). / Sofa to coffee table 40-45 cm; main walkway 90 cm; TV at 1.2-1.6 x diagonal (see tables below).
- **Errores comunes / Common mistakes:**
  - Paso de circulación que cruza el área de conversación. / Walkway cutting through the conversation area.
  - Todo el mobiliario pegado a los muros: distancias de conversación > 3.6 m. / All furniture pushed to the walls: conversation distances > 3.6 m.
  - Sofá seccional sobredimensionado que bloquea puertas o ventanas. / Oversized sectional blocking doors or windows.
  - Lado menor < 2.8 m: no cabe sofá + mesa + paso frontal. / Short side < 2.8 m: sofa + table + front walkway do not fit.
  - TV sobre chimenea (centro de pantalla muy alto, cuello en extensión). / TV over fireplace (screen center too high, neck extension).
