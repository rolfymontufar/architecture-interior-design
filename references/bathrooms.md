| Level | Size | Area | Min side | Source |

| Minimum | 0.90 x 1.50 (3 x 5 ft) | 1.0-1.4 | 0.76 code (2 x 38); 0.90 practical | LA, IRC |
| Recommended | 0.90 x 1.80 to 1.20 x 1.65 | 1.6-2.0 | 0.91 (2 x 46 WC centerline) | CED, AP, BM, NKBA-B20 |
| Generous | e.g. 1.50 x 2.00 | ~3.0 | 1.50 | CED (up to 32 sq ft) |

- Clearances: WC centerline to wall ≥ 38 code, 46 NKBA (NKBA-B20); front clear 53 code, 76 NKBA (NKBA-B4); Europe: WC edge to wall ≥ 20, front ≥ 60 (BN-A, BM).
- Mistakes: inswing door hitting WC or basin (IRC P2705.1.6, NKBA-B2): use pocket or outswing door; full-depth basin (50-55) in a 0.90 m room: use a hand basin ≥ 50 x 40 (BN-S).
