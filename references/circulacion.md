## Resumen rápido / Quick reference

- **Pasillo de vivienda / Dwelling hallway:** mín. 90 cm (US 91.4); rec. 100-120; accesible ES 110 (CTE), UK 90-120 según puerta. / min. 90; rec. 100-120.
- **Puerta, paso libre / Door clear width:** accesible 80 (CTE), 77.5 (UK M4(1)), 85 entrada M4(2); US egreso 81.3. Hojas ES 62.5 / 72.5 / 82.5 / 92.5 x 203.
- **Escalera de vivienda, ES uso restringido / ES dwelling stair:** contrahuella ≤ 20, huella ≥ 22, ancho ≥ 80. Uso general: 13-18.5 / ≥ 28 / ≥ 100.
- **Escalera US / UK:** US contrahuella ≤ 19.7, huella ≥ 25.4, ancho ≥ 91.4; UK privada contrahuella 15-22, huella 22-30, pendiente ≤ 42°.
- **Blondel:** 2C + H = 63 ideal; norma 54-70 (ES), 55-70 (UK).
- **Paso de cabeza / Headroom:** ≥ 200 (US 203.2; UK buhardilla 190).
- **Pasamanos / Handrail:** 90-110 (ES), 86.4-96.5 (US), 90-100 (UK). Barandilla 90 si caída ≤ 6 m, 110 si > 6 m (ES).
- **Rampa accesible / Accessible ramp:** ES 10 % (< 3 m), 8 % (< 6 m), 6 % (resto), tramo ≤ 9 m; US 1:12 (8.33 %).
- **Antepecho / Sill:** ≥ 90 sin barrera (ES); US 61 mín. si caída > 183.
- **Circulación / Circulation:** 10-15 % del área útil (regla práctica).

## Fórmula de Blondel / Blondel's formula

- **Fórmula / Formula:** 2C + H = 62 a 64 cm (C = contrahuella / riser, H = huella / tread). Valor ideal 63 cm. / Ideal 63 cm. (Fuente / Source: NEUF)
- **Rango normativo / Code range:** ES uso general 54 ≤ 2C + H ≤ 70 cm (CTE-SUA); UK 55 ≤ 2R + G ≤ 70 cm (UK-K).
- **Combinaciones cómodas / Comfortable pairs:** C 17 + H 29 = 63; C 17.5 + H 28 = 63; C 18 + H 27 = 63. Regla práctica / Rule of thumb.
- **Vivienda compacta / Compact dwelling:** C 19 + H 25 = 63, aceptable; C 20 + H 22 = 62 es el límite CTE de uso restringido. / acceptable; 20 + 22 is the CTE restricted-use limit.
- **Número de peldaños / Number of risers:** n = altura piso a piso / C, redondear hacia arriba. Ej.: 280 / 17.5 = 16. / n = floor-to-floor height / C, round up. E.g. 280 / 17.5 = 16.
- **Longitud en planta / Plan length:** (n - 1) x H. Ej.: 15 x 28 = 420 cm. / E.g. 15 x 28 = 420 cm.
- **Comprobar / Check:** paso de cabeza ≥ 200 cm en todo el recorrido. / headroom ≥ 200 cm along the whole run.
