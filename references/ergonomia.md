## Principios de diseño / Design principles

- **Alcance:** diseñar para P5 mujer (la persona más pequeña debe alcanzar). / **Reach:** design for P5 female (the smallest user must reach). (PH)
- **Holgura:** diseñar para P95 hombre + calzado (~2.5 cm) y ropa. / **Clearance:** design for P95 male + shoes (~2.5 cm) and clothing. (PH)
- **Ajustable:** si el rango P5 mujer a P95 hombre supera ~10 cm, preferir elementos regulables. / **Adjustable:** if the P5 F to P95 M range exceeds ~10 cm, prefer adjustable elements. (RP)
- **Población:** usar datos de la población usuaria; LatAm es ~5-12 cm más baja que EE. UU. / Alemania en estatura P50 (ver tablas). / **Population:** use data for the actual users; LatAm is ~5-12 cm shorter than US / Germany at P50 stature (see tables). (ACOPLA, ANSUR, GREIL)
