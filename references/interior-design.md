## B1. Design principles
| Principle | Definition | How to apply |
|---|---|---|
| Balance | Visual weight: symmetric, asymmetric, radial | Symmetric = formal (pair of lamps); asymmetric = casual (sofa vs. 2 armchairs) |
| Rhythm | Repetition, alternation, gradation | Repeat a color or material 3 times in a room |
| Emphasis | Dominant focal point | One focal point per room (fireplace, view, art, headboard) |
| Scale | Size relative to room and body | Big furniture overwhelms small rooms; high ceilings call for taller pieces |
| Proportion | Ratio between parts | Coffee table ~2/3 of sofa length; art ~2/3 of width of furniture below (RT, HG) |
| Unity and variety | Coherence with controlled contrast | Limited palette and materials; one strong contrast |
| Harmony | Elements sharing a language | Same hardware style, dominant wood tone |
| Odd grouping | Objects in groups of 3 or 5 | RT (styling) |

## B2. Color
| Rule | Value | Source |
|---|---|---|
| 60-30-10 | 60 % dominant (walls, floor), 30 % secondary (furniture, curtains), 10 % accent (cushions, art) | RT (HG) |
| LRV (light reflectance value) | 0 (black) to 100 (white); high-LRV ceilings increase perceived light | RT |

| Scheme | Description | Effect |
|---|---|---|
| Monochromatic | One hue, several values | Calm, spaciousness |
| Analogous | 2-3 adjacent hues | Soft harmony |
| Complementary | Opposite hues | Contrast, energy; use one as accent |
| Split complementary | One hue + 2 neighbors of its complement | Softer contrast |
| Triadic | 3 equidistant hues | Vibrant; let one dominate |
| Neutral + accent | Whites, greys, beiges + 1 color | Versatile, timeless |

- Warm colors (red, orange, yellow) advance and feel cozy; cool (blue, green, violet) recede and calm.
- Rooms with cool pole-facing light suit warm tones; sunny rooms suit cool tones.
- Small room: walls, ceiling and moldings in related light tones; same wall-ceiling color blurs edges; curtains in wall color; continuous floors between spaces. RT.
- Dark ceiling lowers it visually; dark end wall shortens a long hallway.
- Test paint swatches ≥ 30 x 30 cm (RT) on several walls and at different times of day.

## B3. Layered lighting
| Layer | Function | Typical fixtures |
|---|---|---|
| Ambient | Even light to move around | Ceiling fixtures, downlights, cove, indirect light |
| Task | Localized light for an activity | Under-cabinet, reading lamp, vanity sconces |
| Accent | Highlight objects (≥ 3 x ambient level, RT) | Spots, track, picture lights |
| Decorative | Fixture is the feature | Chandeliers, pendants |

### Illuminance (lux)
- Lux table by room with sources (IES RP-11, SLL LG9, CTE SUA 4): environmental-comfort.md, section "Artificial lighting" (canonical).
- Older adults need much more light for the same task (secondary sources cite 2 to 5 times; av).

## B4. Furniture layout
| Rule | Value (cm) | Source |
|---|---|---|
| Facing seats (conversation) | 180-245 (6-8 ft); max. ~300 | RF; RT |
| Sofa to coffee table | 40-45 (min. 35); canonical: living-dining.md | RF; living-dining.md |
| Main walkway | 76-91 (30-36 in); see living-dining.md | RF |
| Minor path around furniture | ~60 (24 in) | RF |
| Coffee table length | ~2/3 of sofa | RT (HG) |
| Side table height | ± 5 cm of sofa arm | RT |
| TV viewing distance (16:9) | 1.2-1.6 x diagonal (40° THX to 30° SMPTE); table by size in living-dining.md | CALC |

- Steps: 1) define focal point (view, fireplace, TV); 2) place anchor piece (sofa, bed, table) facing or aligned with it; 3) complete U or L conversation group; 4) route traffic around the group, not through.
- Float furniture off walls in large rooms to create zones. RT.
- Do not block windows, doors, outlets or radiators; keep door swings clear.
- Detailed clearances: furniture.md and living-dining.md.

## B8. Texture, pattern and style
- Texture: combine ≥ 3 textures (smooth, rough, glossy, matte, natural) to avoid flatness; neutral rooms depend more on texture. RT.
- Pattern: mix 3 scales (large, medium, small) tied by a common color; one dominant pattern. RT.
- Large low-contrast patterns enlarge visually; horizontal stripes widen, vertical stripes raise.

| Style | Key traits |
|---|---|
| Modern (mid-century) | Clean lines, walnut, tapered legs, organic forms |
| Contemporary | Current trends, neutrals, contrast, metal and glass |
| Minimalist | Few objects, hidden storage, reduced palette |
| Scandinavian | Light wood, whites, natural textiles, functionality |

## B9. Basic acoustics
| Concept | Definition | Value | Source |
|---|---|---|---|
| Absorption | Reduces reverberation within a room | NRC 0 (reflects) to 1 (absorbs) | OEP |
| Insulation | Reduces transmission between rooms (mass, airtightness, decoupling) | Rw, STC, DnT,A (dB, higher = better) | OEP |
| Reverberation time (RT60) | Time to decay 60 dB | Living room 0.3-0.6 s; bedroom ~0.5 s | SA |
| Airborne between dwellings (ES) | DnT,A | ≥ 50 dBA | DBHR |
| Impact between dwellings (ES) | L'nT,w | ≤ 65 dB | DBHR |
| Internal partitions, same dwelling (ES) | RA | ≥ 33 dBA (private residential) | DBHR |

- Absorb: rugs, heavy curtains, upholstery, full bookcases, acoustic panels, acoustic ceiling.
- Insulate: mass, or double drywall with mineral wool in the cavity; seal joints and service penetrations; solid-core doors with seals.
- Hard surfaces (porcelain, glass, concrete) and double-height rooms reverberate: add ≥ 1 large absorbent surface. RT.
- Keep bedrooms off walls shared with TV, kitchen, garage or stairs; see A5 in concepts.md.
